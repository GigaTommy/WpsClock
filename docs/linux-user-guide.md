# WpsClock 麒麟绿色版使用说明

版本：2.4.2-kylin.1-rc1（实机验收候选版）。

2026-11-02，用户已确认该绿色版在目标电脑上可直接使用。保留原交付版本号与程序代码；多屏、声音等逐项验收边界见[验证记录](linux-validation.md)。

适配目标：银河麒麟桌面 V10 SP1 2203，兆芯 x86_64，X11 / UKUI，glibc 2.31，Qt 5.12.8，WPS 12.1.2.28080。

## 复制与启动

1. 将绿色压缩包通过单位允许的方式传入内网。
2. 在麒麟电脑上解压到自己可写的目录。不要在压缩包预览窗口中直接运行。
3. 双击目录中的 **WpsClock**。这是 Linux 可执行程序，没有 `.exe` 扩展名，也不是脚本。
4. 首次运行会打开设置。默认时长为 8 分钟，提前 1 分钟提醒，默认按 F3 开始 / 暂停 / 继续，F4 重新计时。
5. 保存设置后程序继续运行；右键悬浮窗或托盘图标可控制计时、打开设置或退出。

本包不安装软件、不需要 sudo、不联网；使用已确认安装在目标电脑上的 Qt 5 和 X11 运行库，因此无需额外携带这些库。

压缩包保留可执行权限。如果解压工具丢失权限，请右键 WpsClock → 属性 → 权限，勾选“允许作为程序执行”（具体文字取决于文件管理器）。如果单位安全策略禁止执行程序，须按单位流程处理，不能用改后缀或绕过策略的方式解决。

备用启动命令：在解压目录打开终端，执行 `./WpsClock`。此命令启动同一个程序，不执行安装脚本。

## 日常使用

- **自动计时**：开启“自动识别 WPS 放映”，在 WPS 中开始全屏放映。程序需连续确认放映窗口后开始；翻页不重新计时。
- **手动计时**：未计时时按 F3，或右键“开始计时”。手动接管后，本场不随自动窗口识别切换；右键“结束本场”后可重新由自动检测开始。
- **暂停 / 继续**：F3 或右键菜单；时间到且设置了停止计时时，用 F4 重新计时。
- **重置**：F4 或右键“重新计时”，重新使用当前文件规则 / 默认时长；已手动指定本场时长时保留该选择。
- **结束本场**：停止本场计时，不会立即对同一个仍在放映的文件自动重新开始；退出再放映或换另一文件后可自动开始。
- **拖动 / 缩放**：拖动数字区域移动，拖动右下角调整尺寸。多屏同步开启时，每屏记住自己的位置，共用窗口尺寸。
- **多屏**：默认每块屏幕均显示相同计时；关闭多屏同步后跟随已识别的放映屏。
- **锁定 / 点击穿透**：从右键或托盘菜单启用；解除锁定使用托盘菜单。托盘不可用时自动解除锁定，避免失去操作入口。
- **透明**：外观页调整背景不透明度；文字保持清晰。桌面合成不可用时回退为不透明背景。
- **退出**：右键或托盘菜单“退出”。关闭设置窗口不会退出程序。

## 文件时长与会议背景

在“时长与文件”页选择 PPT/PDF，或手工填写文件名，为每个文件设置时长。

- 自动识别依赖窗口提供的文件信息。唯一文件名可以匹配；同名文件有歧义时使用默认时长并提示，不随意选择规则。
- Linux 文件路径区分大小写；Windows 盘符路径不能直接迁移。当前版本不自动导入 Windows XML 设置。
- 已知完整路径与规则路径不一致时，不套用其他路径的同名规则。
- 无法识别文件时，可右键“本场手动指定时长”，保留已用时间。
- 将会议主背景文件勾选为“会议背景”：稳定识别后暂停并隐藏计时；返回原发言文件时继续原计时，换其他发言文件时重新开始。
- 返回文件不明确时维持暂停；如果之前已手动暂停，返回后仍保持暂停。
- 会议背景模式下需要人工接管时，可从托盘使用 F3 对应操作或“重新计时”。

## 声音与到时行为

提前提醒和到时提醒可分别开关。音频路径留空使用本地生成的内置 WAV；自选文件可使用 WAV / MP3，MP3 取决于系统已有解码组件。正式会议前请点击“试听”，并检查当前声音输出是否为投影设备或其他设备。

时间到后默认继续显示超时，也可以选择停止计时。零时长表示不限时正计时，不触发到时提醒。

本版时间到保持放映，不自动发送 Esc，也不提供黑屏。页码与自动单页计时尚未实现，不使用推测页码代替真实数据。

## 设置与卸载

通常保存在当前用户的 `~/.config/WpsClock/WpsClock-Kylin/`；系统设置 XDG_CONFIG_HOME 时使用该目录下的 `WpsClock/WpsClock-Kylin/`。

- `settings.json`：默认时长、文件规则、外观和窗口位置。
- `near.wav`、`end.wav`：首次播放时生成的内置声音。
- `instance.lock`：单实例互斥文件，退出即释放锁；文件本身可以保留。

设置采用原子保存。读取损坏配置时保留原文件，并提示使用默认值；用户明确保存前不覆盖损坏配置。

程序不注册服务、不设置开机启动。退出后删除解压目录即可移除程序；若要同时清除个人设置，再删除上述配置目录。升级时只替换程序，保留配置目录即可。

## 故障反馈

在“版本与检测”页点击“复制诊断（隐藏文件名）”，复制文本反馈。诊断包含系统和 Qt 版本、窗口特征、识别数量与快捷键状态，不主动上传。

- **双击无反应**：在解压目录终端执行 `./WpsClock`，反馈错误文字；不要自行安装外网依赖或修改系统库。
- **没有自动开始**：先用 F3 手动计时；然后在 WPS 正在放映时查看诊断。实际 WPS 窗口特征可能需要后续微调。
- **F3/F4 不生效**：查看是否提示快捷键被占用，换用其他按键或菜单。避免选用本来需要控制 WPS 放映的按键。
- **小窗被盖住**：反馈是普通放映还是演讲者模式，以及是否连接扩展屏。
- **没有声音**：先“试听”，检查音量和输出设备；自定义音频可改用 PCM WAV。

## 首次实机验收（建议使用虚构演示文件）

1. 设置时长 1 分钟、提前 10 秒，试听两个提示音。
2. 普通编辑与最大化不自动开始；F5 放映后自动开始，翻页不重置。
3. F3 暂停 / 继续，F4 重置；小窗保持在 PPT 上方且不影响翻页。
4. 剩余 10 秒与时间到分别变色 / 提醒；退出放映超过 3 秒后恢复待命。
5. 为“发言A.pptx”“发言B.pptx”设置不同时长，再加入“会议背景.pptx”，核对切换、暂停与恢复。
6. 如需投影，验证多屏显示、插拔和位置恢复；退出重开确认设置保留。

隔离 Linux / X11 测试通过不等于麒麟与指定 WPS 版本已经通过以上实机验收。
