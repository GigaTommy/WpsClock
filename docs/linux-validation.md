# Linux 验证范围

版本：2.5.0-kylin.1-rc1。

## 自动化检查

| 检查 | 覆盖范围 |
| --- | --- |
| `model-tests` | 倒计时、暂停恢复、提醒、文件切换、防抖、会议背景、监测切换与手动接管 |
| `appdata-tests` | 标题清洗、同名歧义、完整路径、Linux 大小写、配置读写与权限、语言偏好/回退、文件身份保留、损坏配置及 WAV 格式 |
| `x11-tests` | 模拟编辑/放映窗口、排除无关应用、点击穿透、全局快捷键、按键重复、冲突与窗口销毁 |
| Linux CI | CMake 编译、CTest、隔离 Xvfb/Openbox 桌面与便携包完整性 |

运行方式见[开发说明](linux-development.md)。CI 桌面测试使用合成窗口，不包含真实 WPS、物理投影或声音设备。CI 的便携包检查不等同于麒麟目标环境的二进制兼容性验证。

## 实机检查

以下项目应在目标环境逐项确认：

- 银河麒麟 V10 SP1 / UKUI / X11 与指定 WPS 版本的全屏放映和演讲者视图。
- 会议背景切换时的暂停、音频停止，以及返回发言后的恢复。
- 物理投影、多屏热插拔、不同缩放比例和桌面合成下的透明效果。
- WAV/MP3 试听、物理音频输出和系统解码组件。
- 程序启动、配置持久化、托盘与全局快捷键。

功能检查步骤见[使用说明](linux-user-guide.md)。未提供页码、自动单页计时、自动退出放映和到时黑屏。
