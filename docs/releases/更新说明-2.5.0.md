# WpsClock 2.5.0：多语言便携版

- Windows 与麒麟版增加简体中文、英文和跟随系统语言选择，保留旧配置兼容性。
- 保存语言选择后更新菜单、设置和计时状态，不重置当前计时进度。
- 文件名、路径、规则及自定义前缀保持原值，文件识别不依赖界面语言。
- 翻译编入程序，运行时不增加语言包、下载步骤或额外开发工具。
- 增加中英文说明，明确绿色免安装、普通用户运行、企业内部离线分发和 MIT 授权。
- Windows 单文本构建输出许可证；Linux 便携包附中英文使用说明。

升级前退出程序，保留配置与自定义音频。Windows 配置为 EXE 旁的 XML（或用户目录回退位置），Linux 使用原用户配置目录。新配置中的语言字段缺失时跟随系统；其他系统和原生对话框语言见[使用说明](../user-guide.md)。
