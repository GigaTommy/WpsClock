# WpsClock 2.4.2：自动放映悬浮计时器

WpsClock 在 WPS 放映时显示悬浮计时器，支持文件专属时长、会议背景暂停与恢复、多屏显示及声音提醒。版本变化见 [2.4.2 更新说明](releases/更新说明-2.4.2.md)。

**双击 `WpsClock.exe` → 后台待命 → WPS 开始放映 → 悬浮倒计时。**

## 1. 构建与启动

将完整源码解压到可写目录，保留目录结构。

1. 确认 `apps/windows/` 下有 `WpsClock.cs` 和 `Build.cmd`。
2. 双击 **`apps/windows/Build.cmd`**。
3. 等待窗口显示 **SUCCESS**，按任意键关闭这个一次性的编译窗口。
4. 程序生成在仓库根目录下的 **`.local/agent/apps/windows/WpsClock.exe`**。双击它，即可使用。
5. 此后只需运行 `WpsClock.exe`，不需要再次编译，也不需要运行其他脚本。

`Build.cmd` 使用 Windows .NET Framework 附带的 C# 编译器，离线生成 Windows GUI 程序。

支持 Windows 10 / 11，需要 .NET Framework 4.5+。缺少编译器或编译被系统策略禁用时，脚本会报告失败。

如果生成失败，查看 `.local/agent/apps/windows/build.log`。重新生成前先从托盘退出正在运行的 `WpsClock.exe`，否则旧文件可能被占用。

## 2. 第一次使用与后台运行

1. 双击 `WpsClock.exe`。默认显示蓝底白字小窗，位于屏幕右上角；自动监测已开启。
2. 右键小窗 → **本地设置**。也可以双击小窗，或双击右下角托盘图标。
3. 在 **时长设置** 调整默认时长，例如 `00:20:00`。
4. 在 **控制设置** 设置提前多久提醒；音乐路径留空时使用内置提示音。先点击“试听”。
5. 按 **Enter** 或点击“保存”。设置窗口关闭，程序继续在后台待命。
6. 在 WPS 中放映 PPTX。检测稳定后约 1 秒内自动开始计时，正常翻页不重置。
7. 退出放映后，经过“意外退出不中断计时”设置的宽限时间，恢复待命。默认 3 秒。

关闭设置窗口不会退出程序。**真正退出：右键小窗或托盘图标 → 退出。** 任务管理器中的进程名为 `WpsClock.exe`。

再次双击已经运行的 EXE，会尝试唤起现有设置窗口，避免启动多个计时器。

## 3. 拖动、微调、右上角与多屏

- **左键按住数字区域拖动**，即可微调位置。松开鼠标后自动保存。
- 每块屏幕分别记住位置；窗口限制在所属屏幕内，避免拖出屏幕后找不到。
- 右键 → **恢复右上角位置**，可恢复所有屏幕的默认位置。
- **鼠标靠近边缘或四角**，出现双向箭头后按住左键拖动，可调整长宽。各屏使用相同的保存尺寸，并限制在屏幕内。
- 右键 → **恢复自动尺寸**，恢复按文字自动调整大小。外观设置也可输入宽高，或勾选“自动适应文字尺寸”。
- “放大字体／缩小字体”调整字号；手动尺寸下，文字会按可用空间缩小以避免被裁掉。
- **外观设置 → 背景不透明度**：0% 为透明，100% 为不透明；数字保持清晰。拖动滑块可预览，保存后保留，取消则恢复。
- 默认允许拖动和右键。若不希望小窗接收鼠标，启用 **锁定位置／点击穿透**。
- 锁定后，从**托盘菜单**取消锁定，恢复拖动和右键操作。
- 勾选 **在扩展屏上同步显示计时器**，每块屏幕各显示一个同步小窗；取消时跟随识别到的放映屏。

计时器不抢翻页焦点，可拖到 PPT 留白区域或调整字号。

## 4. 设置页与交互

| 设置页 | 已实现的选项 |
| --- | --- |
| 时长设置 | 默认 HH:mm:ss 时长；PPT/PDF 独立文件时长清单；添加、编辑、删除；当前文件时长；Enter 保存 |
| 控制设置 | 倒计时／正计时；单页计时；提前提醒；到时提醒；内置音或自选 WAV/MP3；浏览、试听；保持全屏／退出全屏／黑屏；退出宽限期；数字闪烁及边框呼吸；到时停止或继续超时；手动暂停／重置；F1–F12 快捷键选择 |
| 外观设置 | 正常和警示前景／背景色；计时与信息字体；放大／缩小；超时前缀；背景独立不透明度；背景透明；宽高／自动尺寸；机器时间；提示前隐藏；没有文档时隐藏；零时长隐藏；页码；控制栏；扩展屏同步；锁定位置 |
| 版本／检测 | 本机检测结果、复制诊断、打开设置目录、兼容识别选项 |

默认暂停快捷键为 **F3**，重置为 **F4**；如被其他软件占用，会提示更换。若只想使用右键菜单，可取消“允许手动暂停、重置计时”，同时关闭全局快捷键。

**到时行为：** 默认保持放映，不打断 PPT；“退出全屏”只向已识别的放映窗口发送 Esc；“黑屏”显示可关闭的黑色覆盖窗，按 Esc 或双击即可返回，不修改 PPT 文件。

**正计时与超时：** 正计时从 00:00 向上走，仍按设置的时长触发到时动作；倒计时到零后默认继续显示负向超时，前缀可改。勾选“停止继续计时”则冻结计时。

**时长为零：** 作为不限时正向计时，不触发到时提醒；是否显示窗口、页码由对应设置决定。

**设置生效：** 背景透明度可即时预览，取消恢复；其余外观在保存后更新；默认时长和文件规则在下一场或重新计时时生效。预览按钮使用已保存的设置；正式计时期间不会让预览覆盖当前计时。

## 5. 打包

将生成的 `WpsClock.exe` 与所需的外部声音文件压缩为 ZIP。使用内置声音时只需 EXE。个人配置 `WpsClock.settings.xml` 应单独保留，避免更新时覆盖设置。

`tools/windows/MakeSfx.cmd` 和 `SFX-Options.txt` 提供可选的 WinRAR 自解压打包配置，输出位于 `.local/agent/packages/sfx/`。

## 6. 设置保存与绿色运行

默认配置保存在 EXE 同目录的 **`WpsClock.settings.xml`**，包括颜色、字体、时间、文件规则和各屏幕位置。退出后仍会保留。

程序目录不可写时，回退到当前用户的 `%LOCALAPPDATA%\WpsClockPortable`，并给出提示。在“版本／检测”页可以打开实际设置目录。

程序不安装服务、不添加开机启动、不创建计划任务、不修改 WPS 文件、不启动网络监听。退出后删除程序和它的配置文件夹即可清理。它使用 Windows 自带系统组件运行。

## 7. 兼容性与限制

- 自动检测结合放映窗口特征和可用的 Office 接口，识别结果受 WPS 版本影响。
- 主要目标是 WPS 全屏放映；同时加入 PowerPoint 和几种独立 PDF 阅读器的窗口识别，但兼容性未经逐一验证。浏览器中的 PDF 不在识别范围。
- 普通编辑界面最大化通常不会触发；某些无边框全屏编辑界面仍可能被兼容识别误判。可取消“版本／检测 → 兼容识别”再测试。
- 单页计时、准确文件全路径和页码依赖当前 WPS 提供 Office 自动化接口。接口不可用时按整场计时，并提示；不会猜页码。
- 文件专属时长优先匹配完整路径；无法获得全路径时尝试唯一文件名匹配。同名不同文件无法区分时使用默认时长。
- 退出全屏动作取决于对应软件是否接受 Esc 消息；多屏、不同缩放比例、放映黑屏／切换窗口需要实测。
- 若放映窗口隐藏超过退出宽限时间，程序会将其视作退出放映；重新显示可能开始新的一场。

## 8. 功能检查

1. 双击 EXE：确认无命令行窗口，托盘和蓝色小窗出现。
2. 拖动小窗，退出重开：确认位置恢复。测试锁定及从托盘解除锁定。
3. 保存默认 `00:01:00`、提前 `00:00:10`，两个声音均开启，确认试听正常。
4. WPS 普通编辑、最大化：应保持待命。F5 放映：应自动开始。
5. 翻页、F3 暂停／继续、F4 重置：确认结果正确。
6. 剩余 10 秒、时间到：确认声音、变色、动画。
7. Esc 退出，超过宽限期后再放映：应从设定时长开始。
8. 如有扩展屏，确认各屏同步，并能独立拖动保存。

有漏识别或误触发时，打开“版本／检测”复制检测信息，注明 Windows 和 WPS 版本。诊断中可能含文档名，可去掉文档名后再反馈。
