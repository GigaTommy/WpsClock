# 示例

| 示例 | 运行方式 | 功能 |
| --- | --- | --- |
| `manual-timers/countdown.html` | 用浏览器打开 | 离线手动计时，不支持强制覆盖 WPS 全屏 |
| `manual-timers/countdown.py` | `python3 examples/manual-timers/countdown.py` | Python 3.9+ 与 Tk 手动计时器 |
| `legacy-windows/WpsClock.ps1` | Windows PowerShell | 基于 WinForms 的自动检测原型 |

正式应用见 `apps/windows`。示例不包含正式应用的全部功能。
